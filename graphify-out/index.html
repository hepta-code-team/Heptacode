Project Map

Frontend

  • app: React shell and routing.
  • pages: wizard and result pages.
  • features: symptoms, emergency UI, result/practice search.
  • lib: API helpers, assessment context, validation.

Backend

  • routes: HTTP entry points.
  • modules/assessment: assessment logic.
  • modules/triage: care level and specialty logic.
  • modules/pdf and modules/fhir: exports.

Shared

  • PatientData: central patient model.
  • TriageSymptom: central symptom model.
  • CareLevel and MedicalSpecialty: result types.

Main Flow

Frontend pages
  -> frontend API helpers
  -> backend routes
  -> backend modules
  -> AI client or local logic
  -> shared result types
  -> result page / PDF / FHIR output
